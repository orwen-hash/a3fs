# A3FS Landing Page

A production-ready static landing page inspired by the supplied editorial advisory reference.

## Highlights

- Large animated hero headline rotating through **CONSULTATIVE**, **CONTRACTING**, **RESIDENTIAL**, and **ACCOUNTING** one word at a time.
- Editorial grid structure, large typography, soft blue brand system, image mosaics, process section, testimonials, service accordion, audience tabs, FAQ accordion, and responsive mobile navigation.
- Local optimized image assets, so the page does not depend on remote image URLs.
- Responsive layouts for desktop, tablet and mobile.
- Accessible navigation, controls, accordions, reduced-motion support and semantic page structure.

## Run locally

Open `index.html` directly or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Production note

The page currently uses `info@a3fs.com` for the contact action. Confirm the official group email and replace it if necessary before publishing.
